# Novapouch

김초엽 작가의 <비구름을 따라서>에 나오는 노바 파우치 게임 프로토타입

두 파우치에서 **사물**과 **속성** 토큰을 하나씩 뽑고, 2~6명이 같은 질문에 한 문장씩 답하며 하나의 세계를 함께 세운 뒤 **성운 기록**에 남기는 협력형 스토리 게임입니다. 내부 독서모임에서 한 판(15~30분)을 끝까지 진행하는 것을 목표로 한 웹 프로토타입입니다.

- 개발 계획: [`docs/DEVELOPMENT_PLAN.md`](docs/DEVELOPMENT_PLAN.md)
- 권리 안내: 작품명과 설정을 외부 공개 서비스에 쓰려면 작가 및 출판권 관계자와의 협의가 먼저 필요합니다. 현재는 내부 검증용입니다.

## 한 판의 흐름

| 단계 | 하는 일 |
|---|---|
| 대기실 | 초대 코드·링크로 2~6명 입장, 방장이 라운드 수(3~6)·답변 시간·고요한 탐사를 정함 |
| 추첨 | 첫 발견자가 A(사물)·B(속성) 파우치를 열고 5초 동안 상상. 속성 다시 흔들기 1회 |
| 명명 | 첫 발견자가 60초 안에 물건의 이름과 한 줄 쓰임을 씀 (30초 연장 1회) |
| 탐사 | 라운드마다 차례인 사람이 질문 카드 3장 중 하나를 고르고, 모두 한 문장씩 답함. 글 대신 선택지로 답해도 됨 |
| 연결 | 장소 → 주민 → 규칙(3) → 사건 순서로 조각을 투표해 확정. 알맞은 문장이 없으면 직접 제안 |
| 기록 | 세계 이름 투표, 별 보내기(놀라움·연결·여운), 공개 범위 결정 후 성운에 저장, 이미지로 내보내기 |

## 구조

```
apps/
  web/          React + Vite 화면 (모바일 우선)
  server/       Fastify + Socket.IO. 방 관리, 타이머, 저장
packages/
  game-core/    게임 규칙 상태 기계 (순수 함수, 서버·화면 공용)
  content/      사물 60 · 속성 60 · 질문 30 · 금칙어 목록
```

- 게임 상태는 서버가 원본을 들고 `reduce(state, action)`으로만 바꿉니다. 화면은 서버가 보낸 스냅샷을 그립니다.
- 사람마다 보이는 상태가 다릅니다: 다른 사람의 초안, 고요한 탐사 중인 답, 숨김·차단된 문장은 가려서 보냅니다.
- 익명 기기 토큰으로 재접속을 복원합니다. 잠깐 끊긴 사람은 20초 동안 기다리고, 방장이 30초 넘게 끊기면 다음 사람에게 방장이 넘어갑니다.
- 저장소는 `.data/` 아래 JSON 파일입니다(세계·차단·신고·이벤트 로그). 운영 규모가 커지면 `FileStore`를 PostgreSQL 구현으로 바꿉니다.

## 실행

Node 22 이상과 pnpm 10이 필요합니다.

```bash
pnpm install
pnpm dev          # 서버 :8787 + 화면 :5173 (http://localhost:5173)
```

한 대의 컴퓨터에서 여러 명을 흉내 내려면 브라우저 창마다 시크릿 창이나 다른 프로필을 쓰세요. 기기 토큰이 브라우저 저장소에 있어서 같은 창끼리는 같은 사람으로 인식됩니다.

운영 빌드는 서버 하나가 화면까지 내보냅니다.

```bash
pnpm build
PORT=8787 DATA_DIR=/var/lib/novapouch pnpm start
```

또는 Docker:

```bash
docker build -t novapouch .
docker run -p 8787:8787 -v novapouch-data:/data novapouch
```

## 검사

```bash
pnpm typecheck
pnpm test         # 규칙·콘텐츠 단위 테스트, 소켓 통합 테스트
pnpm e2e          # Playwright: 세 사람이 한 판을 끝까지 진행 (운영 빌드 기준)
```

E2E에 쓸 Chromium 경로를 바꾸려면 `CHROMIUM_PATH`를 지정하세요. `SCREENSHOT_DIR`을 주면 단계별 화면을 저장합니다.

## 운영 테스트 지표

```bash
pnpm --filter @novapouch/server metrics
```

완주율, 한 판 소요 시간, 기여 균형(지니 계수), 연결 행동, 선택지 비율, 14일 재방문, 금칙어·신고·숨김 횟수를 `.data/`의 로그에서 계산합니다.
